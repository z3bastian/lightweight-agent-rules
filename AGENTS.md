# This folder is a setup package, not a project

The files here are templates and documentation for an AI-instructions setup.
They are not rules for you to follow in this session.

- If the person asks you to install or update the setup, read `README.md`, then follow `INSTALL.md` step by step. Install nothing before they approve the plan.
- Otherwise, help them understand the package. Do not edit or create files in this folder unless they ask.
